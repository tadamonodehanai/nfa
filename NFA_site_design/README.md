# NFA サイトデザイン（静的モック）

WordPress構築用のデザインデータです。CSS・JS・画像・映像はすべて外部ファイルに分けています。

## フォルダ構成
- `*.html` … 全23ページ（TOP／カテゴリトップ11／下層9／お問い合わせ・プライバシー・404）
- `assets/css/style.css` … 全ページ共通のスタイル（1ファイル）
- `assets/js/main.js` … 全ページ共通のスクリプト（要素があるときだけ各機能が動く）
- `assets/js/search.js` … AI検索（デモ版）の仕組み（情報を探すページのみ）
- `assets/js/search-data.js` … AI検索が探す掲載データ（既存サイトから収集した実データ 526件）
- `assets/img/` … 画像（映像のポスター画像と、仮のプレースホルダー画像）
- `assets/video/` … 映像（mv1〜mv4。イメージとして無音ループで使用）

## 外部読み込み
- フォント：Google Fonts（Noto Sans JP／Barlow Condensed）
- アニメーション：GSAP 3.12.5／ScrollTrigger（cdnjs）
- スムーススクロール：Lenis 1.1.13（jsDelivr）

## WordPressへの対応の目安
- 各ページのヘッダー・SPメニュー・関連リンク＆スポンサー帯・フッターは共通 → header.php／footer.php
- カテゴリトップ（cat-1〜4, cat-w, cat-f, cat-s, grassroots, referee, technical, medical）は同じ構成 → カテゴリ（タクソノミー）テンプレート1つ
- お知らせ一覧 → archive、記事詳細 → single
- 画像 `assets/img/ph-*.jpg` は仮置き。本番素材に差し替えてください

## 掲載データについて
- お知らせ・大会/リーグの資料・連絡先・ビジョン・協賛案内・指導者ライセンス等は、既存サイト（https://www.nagano-fa.or.jp）から引用しています（2026年10月時点）
- 各リンクは既存サイトの該当ページ・PDFを直接指しています
- 既存サイトにまだ掲載がない資料は「準備中」表示にしています

## 委員会ごとの運用（WordPress）想定
- お知らせ・大会資料は「委員会（カテゴリ）」単位で投稿 → 各委員会アカウントは自分の委員会カテゴリにのみ投稿する想定
- カテゴリトップの「最新の更新」「大会」「リーグ」「お知らせ」は、その委員会の投稿から自動で並ぶ構成
- TOPの日程タブ・NEWS・PICK UPも同じ投稿データから集約

## AI検索（デモ版）について
- TOPや情報を探すページで入力すると、文から「対象・目的・地域」を読み取り、掲載データを絞り込んで回答を組み立てます
- 回答の下には、根拠にした公式サイトの資料・記事を必ず並べます
- いまはAIの代わりにルールで動かしています（画面に「デモ版」と表示）。本番は `search.js` の「SWAP」の箇所を Claude API ＋掲載ページ検索に差し替え、`search-data.js` を WordPress の投稿・添付ファイルに置き換えます
