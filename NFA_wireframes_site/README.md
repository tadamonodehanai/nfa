# NFA ウェブサイト ワイヤーフレーム一式（相互リンク版）

`index.html` をブラウザで開くと、全ページを遷移しながら確認できます。
GitHub Pages にフォルダごと配置しても動作します（静的HTMLのみ・ビルド不要）。

## 構成
| ファイル | ページ |
|---|---|
| index.html | TOPページ（A〜F） |
| about.html | NFAについて（Life+1） |
| start.html | はじめる・つづける（中間層A面） |
| grow.html | 強くなる・関わる（中間層B面） |
| partner.html | ともに創る（協賛） |
| search.html | 情報を探す（AI探索・動作モック） |
| list.html | 記事一覧テンプレート（動作モック） |
| detail.html | 記事詳細テンプレート（3種切替） |
| teams.html | チーム一覧（動作モック） |
| utility.html | 404／お問い合わせ／静的文書（#form / #doc で面指定可） |

## 見かた
- 右上「設計メモの表示」で赤枠の設計メモと赤ラベルの表示を切り替え（クライアント提示時はオフ推奨）
- 黄色ラベル＝NFA側の確定待ち項目
- `href="#"` のまま残っているリンク＝ワイヤー未作成の下層・外部・添付ファイル
- スマートフォン幅（640px以下）でSPレイアウトに切り替わります

## データについて
search / list / teams 内の記事・チームはすべてダミーデータです。
実装時は WordPress CSV からの変換データ（3軸: 対象・目的・地域）に置換します。
